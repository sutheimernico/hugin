## Decisions taken during the build that are not in the spec

- **`mcp>=2.1,<3`** — SDK 2.1.1 dropped `FastMCP`; the low-level `Server` takes
  `on_list_tools`/`on_call_tool` and its Streamable HTTP paths attach the Starlette request to
  the handler context, so the spec's **stdio fallback was never needed**
  (`docs/adr/0001-mcp-transport.md`). `Mount("/mcp")` redirects and breaks clients — use `Route`.
- **`?since=boot`** on the event stream — the shell opens at the last `kernel.boot`, not seq 0,
  so a page shows this kernel's life, not every run the database holds. `EventLog.max_pid` +
  `ProcessTable.seed` keep pids unique across restarts.
- **Lenient syscall schemas** — `qwen2.5:7b` sends numbers as strings and a single pid outside a
  list; `proc_wait`/`artifact_write` tolerate that rather than fail a mission on a formality.
- **`mcp__hugin` allow-list** — `--permission-mode dontAsk` still refuses MCP tools missing from
  `--allowedTools`; without that token every syscall is denied.
- **No `--bare`** (spec D3, evidence from the 2026-09-05 spike): it rejects the subscription
  login (`terminal_reason=api_error`). Isolation is an own `CLAUDE_CONFIG_DIR` with
  `settings.json` plus symlinked credentials — verified `apiKeySource=none`, ~6.4k instead of
  ~40k prompt tokens. ADR 0002 is Task 30's job.
- **Turn counting** — the CLI emits one assistant message twice with identical usage, so a turn
  counts only when usage follows a `block_stop` *and* differs; the `result` line wins in the end.
- Four documented additions to BINDING frontend types (`Proc.muninWrites`, `Proc.stderrTail`,
  `State.tokenSamples`, `SystemStatus`/`EVENT_KINDS`), each justified in `state/types.ts`.
